# 纸间放映

纸间放映是一款本机运行的个人追番手账。用它查找番剧、管理观看进度、记录单集感想和撰写总评。番剧资料来自 [Bangumi](https://bgm.tv/)，个人记录保存在本机 SQLite 数据库。

- 按作品名、标签、年份和评分查找番剧，查看章节、角色和声优。
- 按集撰写 Markdown 笔记，记录观感和带时间戳的名场面，支持草稿自动保存和剧透遮罩。
- 独立保存作品评分和总评，回顾观看进度、笔记及本周放送。
- 在数据管理中导入或导出个人记录。

## 安装与启动

需要 Node.js 24 LTS、pnpm。使用归档导入时还需要系统的 tar 命令。将 .env.example 复制为 .env，按注释填入自己的 Bangumi 请求标识。令牌可选。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

访问 [本机页面](http://127.0.0.1:5173/)。Windows 用户安装依赖并准备好资料后，可双击 `start.cmd`。服务就绪后，启动器会打开浏览器并退出，服务继续在后台运行。再次双击会打开已有服务。要关闭后台服务，双击 `stop.cmd`。启动错误可查看 `.local/service.log`。默认 API 端口为 3001。

使用 `pnpm dev` 时，服务在前台终端运行，按 Ctrl+C 停止。

首次启动会创建空资料库。已有数据库会在启动时迁移到 v12。

## 可选下载 · 批量导入番剧资料

想开箱浏览番剧，建议先从 [Bangumi 官方 GitHub Releases](https://github.com/bangumi/Archive/releases/latest) 下载一份完整 Wiki 归档。导入后可以在本地搜索和查看作品、章节、角色、声优及制作资料。已有归档文件时，整个导入过程可离线完成，省去逐部访问 Bangumi API。

1. 在官方发布页下载归档 ZIP。最新文件名和下载地址可在 [最新快照清单](https://raw.githubusercontent.com/bangumi/Archive/master/aux/latest.json) 的 `browser_download_url` 找到。
2. 保留 ZIP 原样，将它放到 `data/archive/bangumi.zip`，然后在项目根目录运行 `pnpm import:archive-full`。也可将本机 ZIP 的完整路径作为参数传入。
3. 导入完成后启动网站。单部作品后续可在详情页按栏目刷新。

也可运行 `node scripts/download-archive.mjs`，由脚本从 GitHub 下载、校验并导入。网站已运行且有个人记录时，导入会补齐或更新作品资料，保留原有作品与个人记录的关联。

官方归档提供文本和关联资料。海报网址仍取决于本地已导入的字段或后续地址补齐，图片文件由网站浏览时缓存。已有自己下载的海报缓存时，可以把 `posters/` 复制到新环境数据库旁复用。若所在网络无法访问 Bangumi，仍可通过 GitHub 下载归档并使用本地资料。刷新资料、实时放送和未缓存海报需要各自的上游服务可用。

本项目提供官方下载入口。本机抓取的完整数据库和海报缓存涉及再分发，相关使用范围见 [Bangumi 版权声明与开发者平台协议](https://bgm.tv/about/copyright)。

## 本机数据

Windows 用户可按需补齐海报网址，或把评分人数达到 1,000 的公开动画海报下载到本地缓存。[海报维护说明](POSTER-ADDRESSES.md)

默认数据库位于 `data/anime-note.sqlite`，海报缓存位于数据库旁的 `posters/`。两者会随使用和导入生成。仓库提供源码、迁移、测试和配置模板。本机数据库、个人备份、Bangumi 归档、海报缓存和 .env 由各安装环境独立维护。

当前版本为本机单用户应用。笔记的公开状态用于本机作品讨论区。服务仅监听本机，账号认证与公网部署尚未实现。

## 自动备份个人记录

在另一块硬盘、外接盘或 NAS 上创建目录，把绝对路径填入 `.env` 的 `PERSONAL_BACKUP_DIR`，然后重启服务。服务启动时检查备份，运行期间每 15 分钟检查一次。距上次成功备份满 24 小时才更新，同一目录只保留一份 `paper-screen-personal.json`。新文件通过恢复预检后才替换旧文件。可在数据管理页查看位置、上次成功时间和错误，也可以手动导出。

## 开发

前端使用 React、TypeScript、Vite 与 Tailwind CSS，后端使用 Node.js 和内置 SQLite。

```sh
pnpm test
pnpm build
```

详见 [后端说明](server/README.md) 和 [个人记录 API](server/PERSONAL_API.md)。
